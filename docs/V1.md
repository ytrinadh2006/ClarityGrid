# ClarityGrid V1

## Goal

V1 is about getting the basic analysis loop right before adding more engineering.

### Included

1. File upload
2. Basic validation
3. Data profile
4. Quality score
5. Numeric/categorical exploration
6. Correlation view
7. Deterministic insight rules
8. Basic ML experiment
9. JSON export

## Why these features came first

These are the parts I would normally do manually when opening a new dataset. Building them first gave me a useful foundation without requiring a complicated backend.

## V1 interview explanation

> I started with the data-analysis workflow I already understood. The app first profiles the table, then checks quality, gives a few exploratory views, generates simple findings, and finally lets me test an ML target. I kept the calculations transparent so I can inspect and explain them.
